# Análisis y diseño (TP N.º 7)

Artefactos de análisis y diseño del sistema completo, entregables del Trabajo Práctico N.º 7 de la cátedra Proyecto Final, en el orden de la lista actualizada por la cátedra. Parten de la documentación de producto (`../producto/`) y del stack definido en este repo (`../arquitectura.md`).

| #   | Artefacto                                       | Archivo                                                  |
| --- | ----------------------------------------------- | -------------------------------------------------------- |
| 1   | Modelo de dominio                               | `01-modelo-de-dominio.md`                                |
| 2   | Diagrama de casos de uso                        | `02-diagrama-de-casos-de-uso.md`                         |
| 3   | Modelo de casos de uso                          | `03-modelo-de-casos-de-uso.md`                           |
| 4   | Mockups                                         | `04-mockups.md` (archivo Figma + capturas en `mockups/`) |
| 5   | Especificación de requisitos de software IEEE 830 | `05-especificacion-de-requisitos.md`                   |
| 6   | Documento de arquitectura de software: vistas   | `06-arquitectura-vistas.md`                              |
| 7   | Casos de uso reales: diseño de interfaz gráfica | `07-casos-de-uso-reales.md`                              |
| 8   | Diagramas de colaboración                       | `08-diagramas-de-colaboracion.md`                        |
| 9   | Modelo de base de datos                         | `09-modelo-de-datos.md`                                  |

Cómo se encadenan: el modelo de dominio define los conceptos; el diagrama de casos de uso los relaciona con los actores; el modelo de casos de uso especifica cada caso (flujo principal, extensiones, postcondiciones); los mockups y los casos de uso reales muestran cómo se ven en pantalla; la arquitectura y los diagramas de colaboración muestran cómo se implementan; el modelo de base de datos cierra con el esquema físico.

Los diagramas están en Mermaid y se renderizan en GitHub y en VS Code con la extensión Markdown Preview Mermaid Support.
